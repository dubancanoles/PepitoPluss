# Frontend

Aqui va la interfaz web (RF1, RF2, RF9): registro de persona, administracion
de fuentes, disparo de busquedas y consulta/filtrado de resultados.

Puedes usar React, Vue, o incluso HTML + JS simple con fetch() a la API
en http://localhost:8000. La API expone documentacion interactiva en
http://localhost:8000/docs (Swagger UI de FastAPI) mientras construyes
las pantallas.
